# Discovery Answers

## Q1: Rating Input Method
**Answer:** Number input (type 1-5)
- Simple, consistent with other text fields in the form

## Q2: Comments Input
**Answer:** Opens external editor ($EDITOR)
- Better for longer text input
- Uses system editor preference

## Q3: Custom Fields Editing
**Answer:** Full management (add, edit, delete)
- Can add new custom fields
- Can edit existing fields
- Can delete fields

## Q4: Where to Place These Fields
**Answer:** Add all at the end of the current form
- Straightforward extension of existing form
- No reorganization needed

## Q5: Custom Fields Interface
**Answer:** Vim-like list navigation
- j/k to navigate between fields
- 'a' to add new field
- 'd' to delete field
- Enter to edit selected field

## Q6: Preserve Existing Data
**Answer:** Yes, load and display existing values
- Expected behavior when editing
- User sees current state and can modify
