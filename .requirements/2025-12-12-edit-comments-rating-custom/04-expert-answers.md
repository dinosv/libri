# Expert Answers

## Q7: Rating Validation
**Answer:** Ignore invalid characters (only accept 1-5)
- Cleanest UX, prevents invalid input at source

## Q8: Comments Display in Form
**Answer:** Show truncated preview + "[Ctrl+E] Edit" hint
- Shows user that content exists
- Clear indicator of how to edit

## Q9: Custom Fields - Adding New Field
**Answer:** Two-step prompt (key first, then value)
- Clear workflow
- Prevents confusion about what to enter

## Q10: Default Editor Fallback
**Answer:** vim
- User preference for vim over nano

## Q11: Preserve Original Data
**Answer:** Load all existing values, preserve unchanged fields on save
- Expected editing behavior
- No data loss
